# Обработка матриц на C

Решение задачи из [task.pdf](task.pdf): программа читает из бинарного файла три матрицы A, B, C и ядро D, применяет ядро к каждой матрице и записывает результат в другой бинарный файл.

Решение находится в одном файле `solution.c` и использует стандартную библиотеку C17.

## Содержимое репозитория

| Путь | Назначение |
| --- | --- |
| `solution.c` | Исходный код решения |
| `task.pdf` | Условие задачи |
| `open-tests/open-tests/` | Открытые тесты: входные `.in`, эталонные `.out` и скрипт проверки |
| `test_random.py` | Дополнительные случайные, граничные и большие тесты |

`solution.exe` и `result.bin` являются результатами сборки и запуска. Для проверки задания отправляется только `solution.c`.

## Сборка и запуск

Нужен GCC с поддержкой C17. Все команды ниже выполняются из корня репозитория.

### Windows / PowerShell

```powershell
gcc -std=c17 -O2 -Wall -Wextra -Wpedantic solution.c -o solution.exe
.\solution.exe -i .\open-tests\open-tests\small1.in -o .\result.bin
```

### Linux

```bash
gcc -std=c17 -O2 -Wall -Wextra -Wpedantic solution.c -o solution
./solution -i open-tests/open-tests/small1.in -o result.bin
```

`-i` задаёт входной файл, `-o` задаёт выходной. Флаги можно передавать в любом порядке. При успешном выполнении программа ничего не выводит. Диагностические сообщения записываются в `stderr`.

Выходной файл создаётся при запуске. Если он уже существует, его содержимое перезаписывается.

| Код завершения | Значение |
| --- | --- |
| `0` | Успешное выполнение |
| `10` | Ошибка аргументов, включая отсутствие имени входного или выходного файла |
| `1` | Ошибка открытия, чтения или записи файла, некорректные входные данные либо ошибка выделения памяти |

## Проверка на открытых тестах

Каждый тест состоит из входного файла `<имя>.in` и ожидаемого результата `<имя>.out`. Выход программы нужно сравнивать с эталоном побайтово.

### Один тест в PowerShell

```powershell
.\solution.exe -i .\open-tests\open-tests\small1.in -o .\result.bin
$LASTEXITCODE
fc.exe /b .\result.bin .\open-tests\open-tests\small1.out
$LASTEXITCODE
```

Оба кода завершения должны быть `0`, а сравнение должно сообщить об отсутствии различий. Для другого теста замените `small1` в обоих путях.

### Весь открытый набор в Linux

```bash
bash open-tests/open-tests/run-tests.sh ./solution
```

Скрипт ограничивает выполнение каждого теста 60 секундами. При успешной проверке текущего набора выводится `Passed all 12 tests`.

## Дополнительные тесты

Для `test_random.py` нужен Python 3.9 или новее. Для больших случайных тестов дополнительно используется NumPy:

```powershell
python -m pip install numpy
python test_random.py .\solution.exe
```

В Linux команда запуска: `python3 test_random.py ./solution`. NumPy можно установить в виртуальном окружении через `python3 -m pip install numpy`.

По умолчанию скрипт выполняет:

- Все открытые тесты, найденные в `open-tests/open-tests/`.
- 8 граничных случаев: одноклеточные матрицы, одна строка или столбец, ядро больше матрицы, максимальный нечётный размер одной стороны ядра.
- 500 случайных случаев с матрицами размером от 1 до 12 по каждой стороне и ядрами с нечётными размерами от 1 до 17.
- 3 больших случайных случая с полным сравнением результата с эталоном NumPy.
- 2 случая, в которых суммы выходят за пределы знакового 32-битного типа.

Для маленьких случаев эталон вычисляется простыми циклами на Python. Эталон NumPy суммирует сдвинутые массивы; первые 50 случайных случаев дополнительно используются для сравнения двух эталонов. Для двух проверок больших сумм эталон вычисляется по числу элементов, попавших под постоянное ядро.

Если NumPy не установлен, большие случайные случаи пропускаются с сообщением `SKIP`. Остальные проверки выполняются. Время, выводимое для больших случаев, включает запуск программы и её файловые операции, но не вычисление эталона.

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `--cases` | `500` | Число маленьких случайных случаев |
| `--seed` | `20261006` | Начальное значение генератора случайных данных |
| `--timeout` | `60` | Ограничение времени одного запуска программы, в секундах |
| `--small-only` | Выключен | Пропустить большие случайные случаи и две проверки больших сумм |

Другой набор случайных данных:

```powershell
python test_random.py .\solution.exe --seed 42 --cases 1000
```

Проверка без больших случаев:

```powershell
python test_random.py .\solution.exe --seed 123 --cases 1000 --small-only
```

Повторный запуск с теми же параметрами и версией Python воспроизводит набор данных. Временные файлы удаляются автоматически. При ошибке вход, ожидаемый результат и полученный выход, если он создан, сохраняются в `test-failures/<имя-случая>/`.

## Формат бинарных файлов

Многобайтовые числа записаны в нативном порядке байтов системы. Примеры из условия и открытые тесты используют little-endian. Элементы всех матриц идут по строкам, слева направо и сверху вниз.

### Вход

| Поле | Тип | Количество |
| --- | --- | --- |
| Высота `H`, ширина `W` | `uint32_t` | По одному числу |
| Элементы A, B, C | `uint8_t` | `3 × H × W` чисел |
| Высота `DH`, ширина `DW` ядра | `uint16_t` | По одному числу |
| Элементы D | `int8_t` | `DH × DW` чисел |

Элементы A, B, C чередуются: `A1, B1, C1, A2, B2, C2, ...`. Высота и ширина матриц должны быть положительными, размеры ядра — нечётными и положительными.

### Выход

Сначала записываются `H` и `W`, затем обработанные элементы в порядке `A'1, B'1, C'1, A'2, B'2, C'2, ...`. Ядро в выходной файл не записывается. Размер выхода: `8 + 3 × H × W` байт.

## Алгоритм и устройство кода

Центр ядра совмещается с каждой позицией исходной матрицы. Значения за границами матрицы считаются нулями. Ядро применяется без переворота, как на схеме в условии; математически такая операция называется корреляцией. Размеры результата совпадают с исходными.

После вычисления полной суммы `s` применяется преобразование:

```text
s > 255: результат = s % 251
s < 0:   результат = (-s) % 241
иначе:   результат = s
```

| Функция | Назначение |
| --- | --- |
| `read_input` | Читает размеры и массивы, проверяет чтение и возможность выделения памяти |
| `normalize` | Преобразует итоговую сумму в выходной байт |
| `convolve_and_write` | Вычисляет три матрицы и записывает результат по строкам |
| `main` | Разбирает аргументы, открывает и закрывает файлы, освобождает память |

Суммы накапливаются в `int64_t`. Исходные данные и ядро хранятся целиком, для результата выделяется только одна строка.

Верхняя оценка времени работы: `O(H × W × DH × DW)`. Память: `O(H × W + DH × DW + W)`. Прохождение доступных проверок не гарантирует прохождение закрытых тестов, ограничения размеров и ресурсов которых неизвестны.
